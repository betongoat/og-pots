## 🧪 What does it do?

In newer versions of Minecraft, potions have **lost their enchantment glint**. **OG Pots** brings it back.

Every potion with an effect gets the classic shimmer again, so you can spot your potions in the hotbar, in chests and in your hand at a glance.

- 🎒 **Lightweight**: one tiny jar, no config, no setup
- 🖥️ **Client-side**: works on any server, vanilla included
- 🧩 **No dependencies**: Fabric API is **not** required
- 📦 **One jar for everything**: works on every version from **1.21** to **26.3**

---

## 🔮 Which items shine?

| Item | Glint |
|:--|:--:|
| Potions with an effect | ✅ |
| Splash potions with an effect | ✅ |
| Lingering potions with an effect | ✅ |
| Water bottles | ❌ |
| Awkward, Mundane and Thick potions | ❌ |

> Only potions that actually **do something** shine, so useless brews stay plain, exactly like in the old days.

## ❓ FAQ

<details>
<summary><b>Do I need to install it on the server?</b></summary>

No. OG Pots is client-side only. Put it in your own `mods` folder and play on any server.

</details>

<details>
<summary><b>Do I need Fabric API?</b></summary>

No. You only need Fabric Loader.

</details>

<details>
<summary><b>Why is there only one file for so many versions?</b></summary>

The jar includes code for every version from 1.21 to 26.3. When the game starts, it picks the right code for your version automatically.

</details>

<details>
<summary><b>Is it allowed on PvP servers?</b></summary>

It only changes how potions look on your screen. It gives no gameplay advantage, but always check your server's rules.

</details>
