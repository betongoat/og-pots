OG Pots by betongoat is based on **Shiny Pots** by **nukebob**.

- Original mod: https://modrinth.com/mod/shiny-pots
- Original author: nukebob – https://modrinth.com/user/nukebob
- Original license: Creative Commons Attribution 4.0 International (CC-BY-4.0) – https://creativecommons.org/licenses/by/4.0/

**Changes:** code modified on the basis of the Shiny Pots project. The original mod only supported Minecraft 1.21.10–1.21.11. OG Pots was rewritten to work with every Minecraft version from 1.21 to 26.3 in a single jar: it contains separate mixins for 1.21–1.21.4, 1.21.5–1.21.11 and the unobfuscated 26.1+ versions, and a mixin plugin picks the right one at launch. The mod ID, package, name and icon were also changed. The in-game behaviour is the same as in Shiny Pots.
